# online-food-ordering-system
A C++ console- based online food ordering system developed as aprogramming fundamentals project.
## About the project
This program demonstrates fundamental C++ programming concept through a simple food ordering system.
## Features
Collect customer information.
Displays the food menu and allow item selection.
Take item quantities and supports multiple orders.
Calculates total bill.
Generate a final reciept.
console based project

Variables
Conditional statements
Loops
Functions
Arrays
Basic C++ input/ output
